# Scientific method

The analysis covers ottobasin 722936 (459.97 km² in an Albers equal-area projection) and TerraClass classes primary natural forest vegetation (VNFP, code 1), secondary natural forest vegetation (VNFS, code 2), and silviculture (SIL, code 9). Stable areas retain their class in 2016, 2018, 2020, 2022 and 2024. A 3×3 thematic erosion precedes nearest-neighbour transfer to the 10 m spectral grid. Basin membership uses cell centres. Adjacent BDC tiles 029010 and 030010 are joined without resampling reflectance.

The 184 S2-16D-2 dates span 2017–2024. Ten bands use reflectance scale 10⁻⁴. Eligibility requires valid values in every band, SCL 4–7 and CLEAROB > 0. SCL classifies the scene; retained codes are 4 (vegetation), 5 (non-vegetated surface), 6 (water) and 7 (unclassified). CLEAROB counts clear observations, and PROVENANCE identifies the acquisition used in the composite. These fields remain archived; their use is detailed in supplementary Section S1. At least 101 valid pixels are needed per class–date.

Noise covariance equals half the sample covariance of differences between adjacent same-class valid pixels. The Minimum Noise Fraction (MNF) transform uses an eigenvalue floor of 10⁻¹². The Noise-Whitened Harsanyi–Farrand–Chang (NWHFC) estimate uses a false-alarm probability of 10⁻⁴. For a p × p matrix A, regularization adds δI, where δ = 10⁻⁸ max(|tr(A)|/p, 10⁻¹²). The floor applies to the trace scale before multiplication by 10⁻⁸. The class median dimension, rounded half up and clipped to 2–10, is six for each class. PPI uses 10,000 unit-length directions obtained by normalizing Gaussian random vectors with NumPy default_rng seed 13. Each direction contributes one vote per maximum and minimum. Every positive-vote candidate is retained; canonical grid order resolves ties.

The MNF–PPI numerical reference uses NumPy 2.1.3 and Intel MKL 2023.1. The native lock and a runtime check preserve the eigenvector frame used by the seeded projections. Model and temporal reproduction were executed on Windows with Python 3.13.12 and the locked pip/OpenBLAS packages. Complete reconstruction was also executed on Windows with Python 3.13.5 and the Conda/MKL builds. Their reports are in `verification/`; build identifiers are in `environment-native-win.explicit`.

Development contains 2,422 deliberately selected examples: 515 compatible and 1,907 incompatible. The labeling rules include up to four PPI-ranked, angularly separated spectra per class–date and representative-prioritized spectra. A human reviewer considers visible absorption, red-edge rise and NIR response using spectra, RGB context and quality attributes. Uncertain judgments are resolved before development.

HistGradientBoostingClassifier uses 17 spectral predictors: ten reflectances divided by Euclidean norm, NDVI, EVI, NDWI, NDRE, NDMI, BSI and log(1+norm). Date, class, coordinates and votes are not predictors. Fixed parameters are learning_rate=0.06, max_iter=400, max_bins=255, early_stopping=False and random_state=13. Four configurations compare max_leaf_nodes/min_samples_leaf/L2: 31/20/1, 15/20/1, 15/30/3, 7/40/5.

Five outer and four inner StratifiedGroupKFold partitions group by class–date. Inner predictions select the threshold with maximum recall subject to positive precision ≥0.95 and at least 30 positives; ties prefer precision and a higher threshold. Configurations are ranked by recall, precision, AP and declared order. Each outer model classifies all candidates of its withheld groups and chooses the accepted candidate with highest PPI. The reference evaluates all 519 outer representatives, using 461 existing withheld-group judgments and 58 evaluation-only judgments. The declared representative compatibility goal is global 95%, reported with coverage and class-specific results.

The operational configuration is selected internally on all development examples and refitted to that base. Its 15/30/3 configuration and threshold 0.7542582655199784 accept 56,475 candidates and yield 519 representatives. The 58 evaluation-only judgments are excluded from this fit. External evaluation describes the procedure; operational representatives supply the spectral time series.

Classical Seasonal-Trend decomposition using LOESS (STL), with robust weighting in statsmodels 0.14.4, decomposes Y=T+S+R with period=23, trend=45, low_pass=25, degrees and jumps=1, inner_iter=2 and outer_iter=15. Seasonal windows are 7,9,11,13,15,21,25,31,35. Interpolation is time-linear and supports fitting only. F_S=max(0,1−Var(R)/Var(S+R)); F_T substitutes T for S. Variances are sample variances (ddof=1) computed on all 173 originally observed dates. Gray endpoint shading is visual only.

Sensitivity includes strength ranges, normalized component RMSE relative to window 7, interannual seasonal dispersion, residual correlations at lags 1,23,46, and a descriptive annual residual harmonic. Domain summaries are medians over VIS (B02–B04), red edge (B05–B07), NIR (B08,B8A), and SWIR (B11,B12). These trajectories describe moving spectral extremes. The deliberate labeling design, common annotator, dependence among observations, map provenance, eight cycles and correlated bands delimit interpretation; no regional, productivity or ecological-stability inference is made.
